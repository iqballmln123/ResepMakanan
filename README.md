# Cookify 🍳
Cookify adalah aplikasi mobile untuk berbagi dan menemukan resep makanan sederhana dengan fitur komunitas.  
Target pengguna aplikasi ini adalah mahasiswa, pekerja muda, ibu rumah tangga, dan food enthusiast yang ingin mencari inspirasi resep praktis.

## ✨ Fitur Aplikasi
1. Login & Register pengguna
2. Katalog resep dengan kategori (makanan berat, dessert, minuman)
3. Search & filter resep (berdasarkan bahan, waktu masak, tingkat kesulitan)
4. Step by step cooking dengan foto/Link video
5. Bookmark resep favorit
6. Upload resep sendiri (fitur komunitas)
